# 0.9.25 — «Qué revisar» en Stock de teléfonos · Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** una pestaña «Qué revisar» en Stock de teléfonos con dos tarjetas: «Revisar sin grado» (modelos-color con móviles
`n/a` y como mucho un A) y «Subir B a A» (B y B100 con como mucho un A). Cada fila se despliega con sus IMEI y hay un «Copiar
lista». Sustituye a la hoja PriorizarRevision del Apps Script.

**Architecture:**
- **Solo web.** La página ya carga el stock entero (`GET /api/stock-telefonos`, `useStockTelefonos`, sondeo de 60 s) y lo
  prepara con «Quién lo tiene» (`preparar`). Las reglas van en un módulo puro nuevo, `queRevisar.ts`, que agrupa esos móviles por
  modelo-color y saca las dos listas ya ordenadas, sus cifras y el texto para copiar.
- La página calcula las dos listas con `useMemo` (las necesita para el número de la pestaña) y las pasa a un componente nuevo,
  `VistaQueRevisar.tsx`, que pinta las tarjetas (mismas clases que `TarjetasNsys`), la ayuda, la tabla de la elegida y el
  desplegado.
- El orden de modelos y capacidades es el de la columna lateral: se sacan de `modelo.ts` dos comparadores
  (`compararModelos`, `compararCapacidades`) sin cambiar ese orden.

**Tech Stack:** React 19 + TypeScript, TanStack Query, Vitest + Testing Library + MSW, Playwright (E2E).

**Spec:** `docs/superpowers/specs/2026-11-04-v0925-que-revisar-design.md` (raíz). Prototipo aprobado:
`docs/superpowers/specs/assets/2026-11-04-v0925-prototipo-que-revisar.html`.

## Global Constraints

- **Solo web**: sin cambios en el servidor ni en la base; funciona con el servidor 0.9.24 de producción. Sin migración.
- **Permisos**: SUPERTECNICO y ADMIN, como el resto de Stock de teléfonos. No se toca ninguna ruta.
- **Qué entra**: solo `cuentaComoStock` (estado `STOCK`), con el color y el grado que valen (los de `GET /api/stock-telefonos`).
- **Grados** (el grado llega sin el «100»; la batería nueva va en `bateriaNueva`):
  - con grado: A+, A, A-, B+, B, B-, C, con o sin Ms delante; Ms solo; ID, F, FD, RMA (sin mirar mayúsculas);
  - sin grado: lo demás (`n/a`, vacío, un código raro);

- **Tope**: `MAX_A = 1` (como mucho un A en el modelo-color).
- **Textos exactos**:

/** «Qué revisar» (0.9.25, spec «Qué revisar» §2): de los móviles en stock, los modelos-color con móviles sin grado y pocos A
 *  («Revisar sin grado») y los que tienen B que pueden subir a A con un chasis («Subir B a A»). Sustituye a la hoja
 *  PriorizarRevision del Apps Script. Es puro: la pantalla le pasa los móviles ya preparados (con «Quién lo tiene»). */

/** Como mucho tantos A en el modelo-color para salir en las listas (spec §2.4). */
export const MAX_A = 1

// Con grado (spec §2.3): A+, A, A-, B+, B, B-, C con o sin Ms delante; Ms solo; ID, F, FD y RMA. Sin mirar mayúsculas.
const CON_GRADO = /^(?:ms(?:a\+|a-|a|b\+|b-|b|c)?|a\+|a-|a|b\+|b-|b|c|id|f|fd|rma)$/i
const GRADO_A = /^(?:a\+|a-|a)$/i
const GRADO_B = /^b$/i
const limpio = (grado: string | null | undefined): string => (grado ?? '').trim()

/** ¿Tiene grado? Lo demás (`n/a`, vacío o un código que no es un grado) está sin revisar. */
export const tieneGrado = (grado: string | null | undefined): boolean => CON_GRADO.test(limpio(grado))
/** A+, A o A-, sin Ms (la batería va aparte). */
export const esA = (grado: string | null | undefined): boolean => GRADO_A.test(limpio(grado))
/** Exactamente B, sin Ms: el que sube a A con un chasis. */
export const esB = (grado: string | null | undefined): boolean => GRADO_B.test(limpio(grado))
/** Un móvil con algún trabajo abierto: sale en gris y no cuenta como pendiente (spec §2.6). */
export const conTecnico = (m: Movil): boolean => (m.trabajos ?? []).length > 0

export type Motivo = 'NADA' | 'NINGUN_A' | 'UN_A'
export const TEXTO_MOTIVO: Record<Motivo, string> = { NADA: 'Nada con grado', NINGUN_A: 'Ningún A', UN_A: 'Solo 1 A' }
const ORDEN_MOTIVO: Record<Motivo, number> = { NADA: 0, NINGUN_A: 1, UN_A: 2 }

/** Lo común de un modelo-color de una lista: su clave, el nombre del modelo (con « eSIM»), la capacidad tal cual («128GB» o
 *  «—»), el color, cuántos A tiene en stock y cuáles, y los móviles de esa lista, ordenados. */
export type GrupoBase = {
  clave: string; modelo: string; capacidad: string; color: string; esEsim: boolean; a: number; gradosA: string[]; moviles: Movil[]
}
export type GrupoRevisar = GrupoBase & { motivo: Motivo; pendientes: number; conTecnico: number; conGrado: number }
export type GrupoSubir = GrupoBase & { b: number; bTecnico: number; b100: number; b100Tecnico: number }

type Grupo = { clave: string; modelo: string; capacidad: string; color: string; esEsim: boolean; todos: Movil[] }

/** Los modelos-color del stock (spec §2.1 y §2.2): modelo con « eSIM» si lo es, capacidad y color, con todos sus móviles. */
function grupos(moviles: readonly Movil[]): Grupo[] {
  const mapa = new Map<string, Grupo>()
  for (const m of moviles) {
    if (!cuentaComoStock(m)) continue
    const modelo = nombreMovilNsys(m)
    const capacidad = capacidadDe(m)
    const color = m.color || SIN_DATO
    const clave = `${modelo}|${capacidad}|${color}`
    const g = mapa.get(clave)
    if (g) g.todos.push(m)
    else mapa.set(clave, { clave, modelo, capacidad, color, esEsim: m.esEsim, todos: [m] })
  }
  return [...mapa.values()]
}

/** Los de más días en stock primero (sin días, al final); a igualdad, por IMEI (spec §2.7). */
function ordenarMoviles(moviles: Movil[]): Movil[] {
  const dias = (m: Movil) => m.dias ?? -1
  return [...moviles].sort((x, y) => dias(y) - dias(x) || x.imeiSn.localeCompare(y.imeiSn))
}

/** El orden de los modelos-color (spec §2.7): modelo como la columna lateral, el físico antes que el eSIM, la capacidad como
 *  número y el color por orden alfabético. */
function compararGrupos(x: GrupoBase, y: GrupoBase): number {
  return compararModelos(x.moviles[0], y.moviles[0]) || Number(x.esEsim) - Number(y.esEsim)
    || compararCapacidades(x.capacidad, y.capacidad) || x.color.localeCompare(y.color, 'es')
}

function comun(g: Grupo, deLaLista: Movil[]): GrupoBase {
  const conA = g.todos.filter((m) => esA(m.grado))
  return {
    clave: g.clave, modelo: g.modelo, capacidad: g.capacidad, color: g.color, esEsim: g.esEsim, a: conA.length,
    gradosA: conA.map((m) => limpio(m.grado)), moviles: ordenarMoviles(deLaLista),
  }
}

/** «Revisar sin grado» (spec §2.4): los modelos-color con algún móvil sin grado y como mucho {@link MAX_A} A, por motivo y en el
 *  orden de §2.7. En las cuentas de A y de «con grado» entran todos los móviles del grupo, los tenga un técnico o no. */
export function listaRevisar(moviles: readonly Movil[]): GrupoRevisar[] {
  return grupos(moviles).flatMap((g): GrupoRevisar[] => {
    const sinGrado = g.todos.filter((m) => !tieneGrado(m.grado))
    const base = comun(g, sinGrado)
    if (sinGrado.length === 0 || base.a > MAX_A) return []
    const conGrado = g.todos.length - sinGrado.length
    const tecnico = sinGrado.filter(conTecnico).length
    const motivo: Motivo = conGrado === 0 ? 'NADA' : base.a === 0 ? 'NINGUN_A' : 'UN_A'
    return [{ ...base, motivo, pendientes: sinGrado.length - tecnico, conTecnico: tecnico, conGrado }]
  }).sort((x, y) => ORDEN_MOTIVO[x.motivo] - ORDEN_MOTIVO[y.motivo] || compararGrupos(x, y))
}

/** «Subir B a A» (spec §2.5): los modelos-color con algún B y como mucho {@link MAX_A} A, en el orden de §2.7. */
export function listaSubir(moviles: readonly Movil[]): GrupoSubir[] {
  return grupos(moviles).flatMap((g): GrupoSubir[] => {
    const bs = g.todos.filter((m) => esB(m.grado))
    const base = comun(g, bs)
    if (bs.length === 0 || base.a > MAX_A) return []
    const cuantos = (bateria: boolean, tecnico: boolean) => bs.filter((m) => m.bateriaNueva === bateria && conTecnico(m) === tecnico).length
    return [{ ...base, b: cuantos(false, false), bTecnico: cuantos(false, true), b100: cuantos(true, false), b100Tecnico: cuantos(true, true) }]
  }).sort(compararGrupos)
}

export const pendienteRevisar = (g: GrupoRevisar): boolean => g.pendientes > 0
export const pendienteSubir = (g: GrupoSubir): boolean => g.b + g.b100 > 0

/** La cifra de una tarjeta (spec §3.2): modelos-color con algo pendiente y cuántos móviles pendientes suman. */

export function cifraRevisar(lista: readonly GrupoRevisar[]): Cifra {

  return { grupos: p.length, moviles: p.reduce((n, g) => n + g.b + g.b100, 0) }
}

export const totalQueRevisar = (revisar: readonly GrupoRevisar[], subir: readonly GrupoSubir[]): number =>

// ---------------------------------------------------------------- buscar por palabras clave (spec §3.6)

/** Con tantos caracteres o más, una palabra también busca en el IMEI: así «13» o «128» no encuentran IMEIs. */
export const MIN_IMEI = 6

/** Para comparar: sin acentos, sin mayúsculas y sin espacios. */
const plano = (texto: string): string => texto.normalize('NFD').replace(/[̀-ͯ]/g, '').toLowerCase().replace(/\s+/g, '')

/** Las palabras clave de lo escrito en la caja, ya planas; ninguna si está vacía. */
export const palabrasClave = (texto: string): string[] => texto.split(/\s+/).map(plano).filter(Boolean)

const enImei = (palabra: string, imeiSn: string): boolean => palabra.length >= MIN_IMEI && plano(imeiSn).includes(palabra)

/** ¿Busca alguna palabra este móvil por su IMEI? Su modelo-color se abre solo y la fila sale resaltada. */
export const imeiBuscado = (m: Movil, palabras: readonly string[]): boolean => palabras.some((p) => enImei(p, m.imeiSn))

/** ¿Coincide el modelo-color? Cada palabra tiene que estar en su descripción, en el SKU de alguno de sus móviles o (con
 *  {@link MIN_IMEI} caracteres o más) en el IMEI de uno de los móviles de la lista. */
export function coincide(g: GrupoBase, palabras: readonly string[]): boolean {
  const desc = plano(descripcion(g))
  const skus = g.skus.map(plano)
  return palabras.every((p) => desc.includes(p) || skus.some((s) => s.includes(p)) || g.moviles.some((m) => enImei(p, m.imeiSn)))
}

/** Los modelos-color que coinciden, en el mismo orden; sin palabras, todos. */
export const filtrar = <G extends GrupoBase>(lista: readonly G[], palabras: readonly string[]): G[] =>
  palabras.length === 0 ? [...lista] : lista.filter((g) => coincide(g, palabras))

export const sinCoincidencias = (texto: string): string => `Ningún modelo-color con «${texto.trim()}».`
```

package com.reparaciones.servidor.nsys;

import org.apache.poi.ss.usermodel.BorderStyle;
import org.apache.poi.ss.usermodel.PrintSetup;
import org.apache.poi.ss.util.CellRangeAddress;
import org.apache.poi.xssf.usermodel.XSSFCell;
import org.apache.poi.xssf.usermodel.XSSFCellStyle;
import org.apache.poi.xssf.usermodel.XSSFFont;
import org.apache.poi.xssf.usermodel.XSSFPrintSetup;
import org.apache.poi.xssf.usermodel.XSSFRow;
import org.apache.poi.xssf.usermodel.XSSFSheet;
import org.apache.poi.xssf.usermodel.XSSFWorkbook;

import java.io.ByteArrayOutputStream;
import java.io.IOException;
import java.io.UncheckedIOException;
import java.util.List;
import java.util.regex.Pattern;

/** Una hoja de Excel para imprimir (0.9.25, spec «Qué revisar» §10.3): una cabecera y filas de textos, tal cual las manda la web.
 *  No sabe nada de la lista que imprime. Cabecera en negrita y repetida en cada página, apaisado, ajustado a una página de ancho,
 *  bordes finos en todas las celdas (también las vacías, para escribir a boli) y cada columna tan ancha como su texto más largo. */
final class HojaImprimible {

    static final int MAX_FILAS = 5000;
    static final int MAX_COLUMNAS = 12;
    static final int MAX_CELDA = 200;
    static final int MAX_HOJA = 31;
    /** Una columna no pasa de tantos caracteres de ancho: un texto más largo se corta al imprimir, no ensancha la hoja. */
    static final int ANCHO_MAXIMO = 60;
    /** Lo que Excel no admite en el nombre de una hoja. */
    private static final Pattern PROHIBIDOS = Pattern.compile("[\\[\\]:*?/\\\\]");

    private HojaImprimible() {}

    /** null si la petición vale; si no, el motivo en castellano, para el 400. */
    static String error(String hoja, List<String> columnas, List<List<String>> filas) {
        if (hoja == null || hoja.isBlank()) return "Falta el nombre de la hoja";
        if (hoja.length() > MAX_HOJA) return "El nombre de la hoja pasa de " + MAX_HOJA + " caracteres";
        if (PROHIBIDOS.matcher(hoja).find()) return "El nombre de la hoja no puede llevar [ ] : * ? / \\";
        if (columnas == null || columnas.isEmpty() || columnas.size() > MAX_COLUMNAS)
            return "La hoja lleva de 1 a " + MAX_COLUMNAS + " columnas";
        for (String c : columnas) {
            if (c == null) return "Una columna no tiene nombre";
            if (c.length() > MAX_CELDA) return "El nombre de una columna pasa de " + MAX_CELDA + " caracteres";
        }
        if (filas == null) return "Faltan las filas";
        if (filas.size() > MAX_FILAS) return "Como mucho " + MAX_FILAS + " filas";
        for (int i = 0; i < filas.size(); i++) {
            List<String> fila = filas.get(i);
            if (fila == null || fila.size() != columnas.size())
                return "La fila " + (i + 1) + " no tiene " + columnas.size() + " celdas";
            for (String celda : fila) {
                if (celda == null) return "La fila " + (i + 1) + " lleva una celda nula";
                if (celda.length() > MAX_CELDA) return "Una celda de la fila " + (i + 1) + " pasa de " + MAX_CELDA + " caracteres";
            }
        }
        return null;
    }

    /** El xlsx; la petición ya ha pasado por {@link #error}. */
    static byte[] escribir(String nombreHoja, List<String> columnas, List<List<String>> filas) {
        try (XSSFWorkbook libro = new XSSFWorkbook(); ByteArrayOutputStream salida = new ByteArrayOutputStream()) {
            XSSFSheet hoja = libro.createSheet(nombreHoja);
            XSSFCellStyle cabecera = estilo(libro, true);
            XSSFCellStyle normal = estilo(libro, false);
            int[] anchos = new int[columnas.size()];
            escribirFila(hoja.createRow(0), columnas, cabecera, anchos);
            for (int i = 0; i < filas.size(); i++) escribirFila(hoja.createRow(i + 1), filas.get(i), normal, anchos);
            for (int c = 0; c < anchos.length; c++) hoja.setColumnWidth(c, (Math.min(anchos[c], ANCHO_MAXIMO) + 2) * 256);
            hoja.setRepeatingRows(CellRangeAddress.valueOf("1:1"));
            hoja.setFitToPage(true);
            XSSFPrintSetup impresion = hoja.getPrintSetup();
            impresion.setLandscape(true);
            impresion.setPaperSize(PrintSetup.A4_PAPERSIZE);
            impresion.setFitWidth((short) 1);
            impresion.setFitHeight((short) 0);
            libro.write(salida);
            return salida.toByteArray();
        } catch (IOException e) {
            throw new UncheckedIOException("No se pudo escribir el Excel", e);
        }
    }

    /** Cada celda como texto (un IMEI no pasa a número) y con borde; vacía, en blanco pero con su borde. */
    private static void escribirFila(XSSFRow fila, List<String> valores, XSSFCellStyle estilo, int[] anchos) {
        for (int c = 0; c < valores.size(); c++) {
            String valor = valores.get(c);
            XSSFCell celda = fila.createCell(c);
            celda.setCellStyle(estilo);
            if (valor.isEmpty()) celda.setBlank();

export const esB = (grado: string | null | undefined): boolean => GRADO_B.test(limpio(grado))
/** Un móvil con algún trabajo abierto: sale en gris y no cuenta como pendiente (spec §2.6). */

/** Lo que hace falta de un móvil para saber su modelo-color: lo tienen los del stock y los vendidos de GET …/vendidos. */
type ConModeloColor = { modelo: string | null; modeloMaestro: string | null; esEsim: boolean; capacidad: string | null; color: string | null }

/** La clave del modelo-color (spec §2.2): el modelo con « eSIM» si lo es, la capacidad y el color («—» si no se saben). */
const claveDe = (m: ConModeloColor): string => `${nombreMovilNsys(m)}|${m.capacidad || SIN_DATO}|${m.color || SIN_DATO}`

/** Lo común de un modelo-color de una lista: su clave, el nombre del modelo (con « eSIM»), la capacidad tal cual («128GB» o
 *  «—»), el color, cuántos A tiene en stock y cuáles, los móviles de esa lista, ordenados, y los SKU distintos de todos sus
 *  móviles (para buscar; un `n/a` casi nunca tiene). */
export type GrupoBase = {
  clave: string; modelo: string; capacidad: string; color: string; esEsim: boolean; a: number; gradosA: string[]; skus: string[]
  moviles: Movil[]
}
/** `vendidos` y `dePedido`, los de «Pedidos 15 d»; `pedidos`, su suma, que manda en el orden (spec §10.2). */
export type GrupoRevisar = GrupoBase & {
  motivo: Motivo; pendientes: number; conTecnico: number; conGrado: number; vendidos: number; dePedido: number; pedidos: number
}

type Grupo = { clave: string; modelo: string; capacidad: string; color: string; esEsim: boolean; todos: Movil[] }

/** Los modelos-color del stock (spec §2.1 y §2.2): modelo con « eSIM» si lo es, capacidad y color, con todos sus móviles. */
function grupos(moviles: readonly Movil[]): Grupo[] {
  const mapa = new Map<string, Grupo>()
  for (const m of moviles) {
    if (!cuentaComoStock(m)) continue
    const clave = claveDe(m)
    const g = mapa.get(clave)
    if (g) g.todos.push(m)
    else mapa.set(clave, { clave, modelo: nombreMovilNsys(m), capacidad: m.capacidad || SIN_DATO, color: m.color || SIN_DATO, esEsim: m.esEsim, todos: [m] })
  }
  return [...mapa.values()]
}

/** Los de más días en stock primero (sin días, al final); a igualdad, por IMEI (spec §2.7). */
function ordenarMoviles(moviles: Movil[]): Movil[] {
  const dias = (m: Movil) => m.dias ?? -1
  return [...moviles].sort((x, y) => dias(y) - dias(x) || x.imeiSn.localeCompare(y.imeiSn))
}

/** El orden de los modelos-color (spec §2.7): modelo como la columna lateral, el físico antes que el eSIM, la capacidad como
 *  número y el color por orden alfabético. */
function compararGrupos(x: GrupoBase, y: GrupoBase): number {
  return compararModelos(x.moviles[0], y.moviles[0]) || Number(x.esEsim) - Number(y.esEsim)
    || compararCapacidades(x.capacidad, y.capacidad) || x.color.localeCompare(y.color, 'es')
}

function comun(g: Grupo, deLaLista: Movil[]): GrupoBase {
  const conA = g.todos.filter((m) => esA(m.grado))
  return {
    clave: g.clave, modelo: g.modelo, capacidad: g.capacidad, color: g.color, esEsim: g.esEsim, a: conA.length,
    gradosA: conA.map((m) => limpio(m.grado)),
    skus: [...new Set(g.todos.flatMap((m) => (m.sku ? [m.sku] : [])))],
    moviles: ordenarMoviles(deLaLista),
  }
}

const sumar = (mapa: Map<string, number>, clave: string) => mapa.set(clave, (mapa.get(clave) ?? 0) + 1)

/** «Revisar sin grado» (spec §10.1): todos los modelos-color con algún móvil sin grado, lo más pedido primero («Pedidos 15 d»:
 *  los `vendidos` y los de pedido de su modelo-color) y, a igualdad, lo que más queda sin revisar; después, por motivo y en el
 *  orden de §2.7. En las cuentas de A y de «con grado» entran todos los móviles del grupo, los tenga un técnico o no. Un vendido
 *  que hoy está de pedido cuenta una vez, como de pedido. */
export function listaRevisar(moviles: readonly Movil[], vendidos: readonly Vendido[] = []): GrupoRevisar[] {
  const dePedido = new Map<string, number>()
  const imeisDePedido = new Set<string>()
  for (const m of moviles) {
    if (m.estado !== 'DE_PEDIDO') continue
    sumar(dePedido, claveDe(m))
    imeisDePedido.add(m.imeiSn)
  }
  const vendidosPorClave = new Map<string, number>()
  for (const v of vendidos) if (!imeisDePedido.has(v.imeiSn)) sumar(vendidosPorClave, claveDe(v))
  return grupos(moviles).flatMap((g): GrupoRevisar[] => {
    const sinGrado = g.todos.filter((m) => !tieneGrado(m.grado))
    if (sinGrado.length === 0) return []
    const base = comun(g, sinGrado)
    const conGrado = g.todos.length - sinGrado.length
    const tecnico = sinGrado.filter(conTecnico).length
    const motivo: Motivo = conGrado === 0 ? 'NADA' : base.a === 0 ? 'NINGUN_A' : base.a === 1 ? 'UN_A' : 'CON_A'
    const v = vendidosPorClave.get(g.clave) ?? 0
    const p = dePedido.get(g.clave) ?? 0
    return [{ ...base, motivo, pendientes: sinGrado.length - tecnico, conTecnico: tecnico, conGrado, vendidos: v, dePedido: p, pedidos: v + p }]
  }).sort((x, y) => y.pedidos - x.pedidos || y.pendientes - x.pendientes || ORDEN_MOTIVO[x.motivo] - ORDEN_MOTIVO[y.motivo]
    || compararGrupos(x, y))
}

/** «Subir B a A» (spec §2.5): los modelos-color con algún B y como mucho {@link MAX_A} A, en el orden de §2.7. */
export function listaSubir(moviles: readonly Movil[]): GrupoSubir[] {
  return grupos(moviles).flatMap((g): GrupoSubir[] => {
    const bs = g.todos.filter((m) => esB(m.grado))
    const base = comun(g, bs)
    if (bs.length === 0 || base.a > MAX_A) return []
    const cuantos = (bateria: boolean, tecnico: boolean) => bs.filter((m) => Boolean(m.bateriaNueva) === bateria && conTecnico(m) === tecnico).length
    return [{ ...base, b: cuantos(false, false), bTecnico: cuantos(false, true), b100: cuantos(true, false), b100Tecnico: cuantos(true, true) }]
  }).sort(compararGrupos)
}

export const pendienteRevisar = (g: GrupoRevisar): boolean => g.pendientes > 0
export const pendienteSubir = (g: GrupoSubir): boolean => g.b + g.b100 > 0

/** «Solo con 3 o más sin revisar» (spec §10.1): encendido, solo los modelos-color con {@link MIN_PENDIENTES} pendientes o más;
 *  apagado, todos. En el mismo orden. */
export const soloTres = (lista: readonly GrupoRevisar[], encendido: boolean): GrupoRevisar[] =>
  encendido ? lista.filter((g) => g.pendientes >= MIN_PENDIENTES) : [...lista]

/** La cifra de una tarjeta (spec §3.2): modelos-color con algo pendiente y cuántos móviles pendientes suman. */

/** Con tantos caracteres o más, una palabra también busca en el IMEI: así «13» o «128» no encuentran IMEIs. */
export const MIN_IMEI = 6

/** Para comparar: sin acentos, sin mayúsculas y sin espacios. */
const plano = (texto: string): string => texto.normalize('NFD').replace(/[̀-ͯ]/g, '').toLowerCase().replace(/\s+/g, '')

/** Las palabras clave de lo escrito en la caja, ya planas; ninguna si está vacía. */
export const palabrasClave = (texto: string): string[] => texto.split(/\s+/).map(plano).filter(Boolean)

const enImei = (palabra: string, imeiSn: string): boolean => palabra.length >= MIN_IMEI && plano(imeiSn).includes(palabra)

/** ¿Busca alguna palabra este móvil por su IMEI? Su modelo-color se abre solo y la fila sale resaltada. */
export const imeiBuscado = (m: Movil, palabras: readonly string[]): boolean => palabras.some((p) => enImei(p, m.imeiSn))

/** Las piezas de la descripción con las que se busca: cada palabra del modelo, la capacidad y el color, y cada uno de los tres
 *  entero y sin espacios («iphone12pro», «128gb», «titanionegro»). */
function piezas(g: GrupoBase): string[] {
  const partes = [g.modelo, g.capacidad === SIN_DATO ? '' : textoCapacidad(g.capacidad), g.color === SIN_DATO ? '' : g.color]
  return partes.flatMap((p) => [...p.split(/\s+/).map(plano), plano(p)]).filter(Boolean)
}

/** Una palabra encaja con una pieza: si es un número, la pieza tiene que ser ese número («12» no encuentra «128» ni «512»); si
 *  no, la pieza tiene que empezar por ella («tit» encuentra «titanio»). */
const encaja = (palabra: string, pieza: string): boolean => (/^\d+$/.test(palabra) ? pieza === palabra : pieza.startsWith(palabra))

/** ¿Coincide el modelo-color? Cada palabra tiene que encajar con una pieza de su descripción, ser el principio del SKU de alguno
 *  de sus móviles o (con {@link MIN_IMEI} caracteres o más) estar en el IMEI de uno de los móviles de la lista. */
export function coincide(g: GrupoBase, palabras: readonly string[]): boolean {
  const ps = piezas(g)
  const skus = g.skus.map(plano)
  return palabras.every((p) => ps.some((x) => encaja(p, x)) || skus.some((s) => s.startsWith(p)) || g.moviles.some((m) => enImei(p, m.imeiSn)))
}

/** Los modelos-color que coinciden, en el mismo orden; sin palabras, todos. */
export const filtrar = <G extends GrupoBase>(lista: readonly G[], palabras: readonly string[]): G[] =>
  palabras.length === 0 ? [...lista] : lista.filter((g) => coincide(g, palabras))

// que-revisar.spec.ts (0.9.25, spec 2026-11-04-v0925-que-revisar-design.md §3 y §10): el supertécnico abre Stock de teléfonos →
// «Qué revisar», ve las dos tarjetas con su cifra, el interruptor «Solo con 3 o más sin revisar» encendido, la columna «Pedidos
// 15 d» (y mide lo que tarda GET …/vendidos con el histórico entero), descarga el Excel y, si hay algún modelo-color, lo despliega
// y ve un IMEI. Solo LEE: los vendidos y el Excel no tocan la base, el Excel se guarda en una «Guardar como» falsa (en la memoria
// de la página) y no se apunta ningún IMEI en el código. Como todas las E2E, solo contra PREPRODUCCIÓN: se niega a seguir sin el
// letrero.
const LETRERO_PRE = 'PREPRODUCCIÓN · datos de prueba'
const COLUMNAS_EXCEL = ['Modelo', 'Capacidad', 'Color', 'IMEI', 'Ubicación', 'Días en stock', 'Pedidos 15 d', 'Revisado']

type Guardado = { nombre: string; bytes: number[] }

/** «Guardar como» falsa, como en plantillas-nsys.spec.ts (Chromium sin cabeza no abre la de verdad): da un fichero con el nombre
 *  propuesto y apunta en `guardadosE2E` lo que la web escribe en él. Va como script de la página: sin nada de fuera. */
function guardarComoFalso() {
  const guardados: { nombre: string; bytes: number[] }[] = []
  Reflect.set(globalThis, 'guardadosE2E', guardados)
  Reflect.set(globalThis, 'showSaveFilePicker', async (opciones?: { suggestedName?: string }) => {
    const nombre = opciones?.suggestedName ?? 'sin-nombre'
    const partes: Blob[] = []
    return {
      name: nombre,
      createWritable: async () => ({
        write: async (b: Blob) => { partes.push(b) },
        close: async () => { guardados.push({ nombre, bytes: Array.from(new Uint8Array(await new Blob(partes).arrayBuffer())) }) },
        abort: async () => {},
      }),
    }
  })
}

test('«Qué revisar» enseña sus tarjetas, «Pedidos 15 d» y el interruptor, descarga el Excel y despliega un modelo-color', async ({ page }) => {
  const { usuario, clave } = credenciales('E2E_USER', 'E2E_PASS')
  await page.addInitScript(guardarComoFalso)
  await page.goto('/login')
  await page.getByPlaceholder('Usuario').fill(usuario)
  await page.getByPlaceholder('Contraseña').fill(clave)
  await page.getByRole('button', { name: 'Iniciar Sesión' }).click()
  await expect(page.getByText('FSGR:')).toBeVisible()
  expect(await page.getByText(LETRERO_PRE).isVisible(), `solo corre contra PREPRODUCCIÓN (letrero «${LETRERO_PRE}»)`).toBe(true)

  await page.getByRole('navigation', { name: 'Sub-navegación' }).getByRole('link', { name: 'Stock de teléfonos', exact: true }).click()
  await expect(page.getByText(/^\d+ móviles? en stock$/)).toBeVisible()
  const pestana = page.getByRole('button', { name: /^Qué revisar \(\d+\)$/ })
  const vendidos = page.waitForResponse((r) => new URL(r.url()).pathname === '/api/stock-telefonos/vendidos')
  const antes = Date.now()
  await pestana.click()
  const respuesta = await vendidos
  await respuesta.finished()
  const ms = Date.now() - antes
  console.log(`GET /api/stock-telefonos/vendidos: ${ms} ms`)
  expect(respuesta.status(), 'los vendidos (servidor 0.9.25)').toBe(200)
  expect(ms, 'los vendidos, por debajo del límite de 15 s').toBeLessThan(15_000)
  await expect(pestana).toHaveAttribute('aria-pressed', 'true')
  for (const nombre of ['Revisar sin grado', 'Subir B a A'])
    await expect(page.getByRole('article', { name: nombre })).toContainText(/\d+ modelos?-color · \d+ móvil(es)?/)

  const tres = page.getByRole('switch', { name: 'Solo con 3 o más sin revisar' })
  await expect(tres).toHaveAttribute('aria-checked', 'true')
  const excel = page.getByRole('button', { name: /^⬇ Descargar Excel/ })
  await expect(excel).toBeVisible()
  const tabla = page.getByRole('table', { name: 'Revisar sin grado' })
  if (await tabla.count() === 0) {
    await expect(page.getByText(/^(Nada que revisar|Ningún modelo-color con 3 o más sin revisar)/)).toBeVisible()
    await tres.click()
    await expect(tres).toHaveAttribute('aria-checked', 'false')
  }
  if (await tabla.count() === 0) {
    await expect(page.getByText(/^Nada que revisar/)).toBeVisible()
    return
  }
  await expect(tabla.getByRole('columnheader', { name: 'Pedidos 15 d', exact: true })).toBeVisible()

  const n = Number(/\((\d+)\)$/.exec((await excel.textContent()) ?? '')?.[1] ?? '0')
  if (n > 0) {
    const pedida = page.waitForResponse((r) => new URL(r.url()).pathname === '/api/stock-telefonos/que-revisar/excel')
    await excel.click()
    expect((await pedida).status(), 'el Excel (servidor 0.9.25)').toBe(200)
    await expect(page.getByTestId('aviso-breve')).toContainText(`Descargado: ${n} móvil`)
    const guardado = await page.evaluate(() => (Reflect.get(globalThis, 'guardadosE2E') as Guardado[]).at(-1))
    expect(guardado?.nombre).toMatch(/^Que_revisar_sin_grado_\d{4}-\d{2}-\d{2}\.xlsx$/)
    const xlsx = leerXlsx(Buffer.from(guardado!.bytes))
    COLUMNAS_EXCEL.forEach((c, i) => expect(xlsx.celda(`${'ABCDEFGH'[i]}1`).valor, `cabecera ${c}`).toBe(c))
    expect(xlsx.filasConDatos(2, 'D'), 'una fila por móvil, con su IMEI').toHaveLength(n)
  }

  const desplegar = page.getByRole('button', { name: /^Ver los móviles de / })
  await desplegar.first().click()
  await expect(desplegar.first()).toHaveAttribute('aria-expanded', 'true')
  await expect(page.getByRole('table', { name: /^Móviles de / }).getByRole('button', { name: /^Abrir / }).first()).toBeVisible()
})
```
