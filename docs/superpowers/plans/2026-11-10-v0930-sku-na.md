# 0.9.30 — SKU para los móviles con grado n/a: plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** que un móvil con grado `n/a` o en blanco lleve como SKU el «SKU sin grado» del maestro + `NA` (`i13128AzulNA`; en un eSIM, `i14eSIM128MedianocheNA`), en vez de quedarse sin SKU.

**Architecture:** una clase pura nueva, `SkuNa`, con la regla. La usan los dos sitios que hoy calculan un SKU: `Comparador.construir` (lo que se guarda en `Nsys_movil` al importar) y `Maestro` (el SKU del taller, vía `LoQueVale`). Un cambio que solo toca el SKU se guarda sin mover `CAMBIADO`, porque esa fecha es el día de baja que usa `VueltaNsys`.

**Tech Stack:** Java 17, Spring Boot 3.3.4, JUnit 5, Maven. Solo `gestion-reparaciones-servidor`. Sin web ni base de datos.

**Spec:** `docs/superpowers/specs/2026-11-10-v0930-sku-na-design.md`

## Global Constraints

- Sufijo: exactamente `NA`, pegado al final, sin guion.
- Solo con grado `n/a` (sin distinguir mayúsculas, sin espacios a los lados), en blanco o null. No es `GradoTaller.Grupo.COMO_NA`: un código desconocido sigue sin SKU.
- Si el maestro da SKU web para ese producto y grado, manda el del maestro.
- eSIM: `eSIM` justo delante de la capacidad dentro del «SKU sin grado». Si la capacidad no aparece, sin SKU.
- El SKU calculado no puede pasar de `AnchosNsys.SKU` (60); si pasa, sin SKU.
- Sin migración, sin cambios en la web, sin cambios en las descargas.
- Commits en español, estilo `feat: … (0.9.30)`, **sin** `Co-Authored-By`.
- No hacer merge, push ni tags: los decide el usuario.

```java
package com.reparaciones.servidor.nsys;

import java.util.Locale;

/** El SKU de un móvil sin grado (spec 0.9.30 §3): el maestro no da SKU web para el grado «n/a», así que el programa pone el
 *  «SKU sin grado» de su fila (modelo + capacidad + color) con «NA» en el sitio del grado: «i13128AzulNA». Si el maestro da
 *  SKU, manda el del maestro. Solo para «n/a» y en blanco: un código desconocido sigue sin SKU. Es puro. */
public final class SkuNa {

    static final String SUFIJO = "NA";
    private static final String ESIM = "eSIM";

    private SkuNa() {}

    /** Sin grado en NSYS: «n/a» (sin distinguir mayúsculas ni espacios a los lados), en blanco o null. Más estrecho que
     *  {@code GradoTaller.Grupo.COMO_NA}, que incluye también los códigos desconocidos. */
    public static boolean esNa(String grade) {
        return grade == null || grade.isBlank() || grade.strip().equalsIgnoreCase("n/a");
    }

    /** El SKU de un móvil con la fila del maestro de su «Goods + Grade»: el SKU web si lo trae; si no, el calculado; si
     *  tampoco, lo que traiga el maestro (nada). null sin fila. */
    public static String de(ProductoMaestro p, String grade) {
        if (p == null) return null;
        if (p.skuWeb() != null && !p.skuWeb().isBlank()) return p.skuWeb();
        String calculado = calculado(p, grade);
        return calculado != null ? calculado : p.skuWeb();
    }

    /** El «SKU sin grado» de la fila + «NA», si el grado es «n/a» o en blanco. null si no lo es, si la fila no trae «SKU
     *  sin grado», si es un eSIM y no se sabe dónde va «eSIM», o si no cabe en la columna. */
    public static String calculado(ProductoMaestro p, String grade) {
        if (p == null || !esNa(grade) || p.skuSinGrado() == null || p.skuSinGrado().isBlank()) return null;
        String base = p.skuSinGrado().strip();
        if (p.esEsim()) base = conEsim(base, p.capacidad());
        if (base == null) return null;
        String sku = base + SUFIJO;
        return sku.length() > AnchosNsys.SKU ? null : sku;
    }

    /** El «SKU sin grado» de un eSIM no lleva «eSIM» («i14128Medianoche» para el SKU web «i14eSIM128MedianocheA100»): va
     *  justo delante de la capacidad (la última vez que aparece: «i12128Negro» → «i12eSIM128Negro»). null si la capacidad no
     *  aparece: mejor sin SKU que uno mal formado. */
    static String conEsim(String base, String capacidad) {
        String enMinusculas = base.toLowerCase(Locale.ROOT);
        if (enMinusculas.contains("esim")) return base;
        if (capacidad == null) return null;
        String cap = capacidad.replaceAll("\\s+", "").replaceFirst("(?i)GB$", "").toLowerCase(Locale.ROOT);
        if (cap.isEmpty()) return null;
        int en = enMinusculas.lastIndexOf(cap);
        return en < 0 ? null : base.substring(0, en) + ESIM + base.substring(en);
    }
}
```

```java
    /** Los SKU del modelo por color y grado, solo los que tienen uno (las mismas reglas que {@link #sku}). */
    public List<SkuMaestro> skus(MovilNsys m) {
        Map<List<String>, List<ProductoMaestro>> porCombinacion = new LinkedHashMap<>();
        delModelo(m).filter(p -> p.color() != null && p.calidadDetalle() != null).forEach(p ->
                porCombinacion.computeIfAbsent(List.of(p.color().strip(), p.calidadDetalle().strip()), k -> new ArrayList<>())
                        .add(p));
        List<SkuMaestro> skus = new ArrayList<>();
        porCombinacion.forEach((k, filas) -> {
            String sku = unSku(filas, k.get(1));
            if (sku != null) skus.add(new SkuMaestro(k.get(0), k.get(1), sku));
        });
        return skus;
    }

    /** El SKU de las filas de un color y un grado: su único SKU_WEB; con varios distintos, ninguno; sin ninguno, el de los
     *  «n/a» si las filas coinciden en uno. */
    private static String unSku(List<ProductoMaestro> filas, String grado) {
        List<String> web = filas.stream().map(ProductoMaestro::skuWeb).filter(s -> s != null && !s.isBlank()).distinct().toList();
        if (web.size() == 1) return web.get(0);
        if (!web.isEmpty()) return null;
        List<String> na = filas.stream().map(p -> SkuNa.calculado(p, grado)).filter(Objects::nonNull).distinct().toList();
        return na.size() == 1 ? na.get(0) : null;
    }
```
