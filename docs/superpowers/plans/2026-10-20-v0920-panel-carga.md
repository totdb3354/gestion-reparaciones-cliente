# 0.9.20 — Panel flotante «Carga de técnicos» en directo · Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** que la carga de técnicos sea un panel flotante que no bloquea, visible en cualquier pantalla del supertécnico y del
admin, que se mueve, se minimiza a una pastilla, recuerda cómo se dejó y se mantiene al día solo (lo propio al momento, lo
demás cada 30 s).

**Architecture:**
- **Solo web.** Ni servidor ni base de datos: la consulta `GET /api/reparaciones/carga-tecnicos` ya existe.
- **`shared`:**
  - `lib/anclaPanel.ts`: funciones puras de la posición (esquina + distancias, recorte a la ventana);
  - `lib/panelCarga.ts`: lo que recuerda el navegador (store leído de `localStorage`) y el aviso de un solo uso del filtro de técnico;
  - `lib/store.ts`: `crearStoreLeido`, un store que relee su fuente al reiniciarse;
  - `api/cargaTecnicos.ts`: la clave de la consulta;
  - `api/queryClient.ts`: la regla general «cada escritura vuelve a pedir la carga».
- **Módulo `taller/asignaciones/panel/`:** el panel, la pastilla, la fila estrecha, el toggle, el arrastre y el botón de la barra.
- **Montaje:**
  - el panel se monta en `AppLayout` y el botón en `TopBar`;
  - Asignaciones abre el panel y recibe el filtro;
  - la ventana modal `CargaTecnicosDialog` se borra.

**Tech Stack:** React 19 + TypeScript, React Router 7, TanStack Query 5 y Tailwind 4. Pruebas con Vitest, Testing Library,
user-event, MSW y Playwright.

## Ajustes a la spec (se suben a la spec en el commit del plan)

1. **Regla general (§2 «Actualización» y §5):**
   - recarga tras **cada escritura que termina, bien o con error**: un 409 es que algo cambió por debajo, y la ventana de
     antes también recargaba en ese caso;

   pulsarlo entonces lo cierra.
3. **Entrega (§6):** la rama es `dev_v0920_panel_carga`, por la convención de ramas por área (antes ponía `feature/panel-carga`).
4. **Piezas (§4):**
   - `CLAVE_CARGA_TECNICOS` va en `shared/api/cargaTecnicos.ts`;
   - el botón de la barra es `BotonPanelCarga`, en el módulo del panel;
   - `store.ts` gana `crearStoreLeido`;
   - la preparación de las pruebas vacía el almacenamiento **antes** de reiniciar los stores.

```ts
/** Para estado de módulo (se crea una vez, al cargar el fichero): el store queda registrado para reiniciarStores y no se
 *  da de baja, así que no debe crearse dentro de un componente. */
export function crearStore<T>(inicial: T): Store<T> {
  return registrar(() => inicial)
}

/** Como crearStore, pero el valor de partida se LEE (p. ej. de localStorage) al crear el store y cada vez que se reinicia:
 *  reiniciarStores no lo devuelve a lo que había al cargar el fichero, sino a lo que diga la fuente en ese momento (0.9.20,
 *  panel de carga: lo recordado es del navegador y sobrevive al cierre de sesión). */
export function crearStoreLeido<T>(leer: () => T): Store<T> {
  return registrar(leer)
}

function registrar<T>(inicial: () => T): Store<T> {
  let valor = inicial()
  const listeners = new Set<() => void>()
  const avisar = () => listeners.forEach((l) => l())
  const store: Store<T> = {
    get: () => valor,
    set: (v) => {
      valor = typeof v === 'function' ? (v as (prev: T) => T)(valor) : v
      avisar()
    },
    subscribe: (cb) => {
      listeners.add(cb)
      return () => listeners.delete(cb)
    },
    reset: () => {
      valor = inicial()
      avisar()
    },
  }
  registrados.add(store)
  return store
}
```

```ts
/**
 * Dónde va el panel flotante de la carga de técnicos (spec 0.9.20 §2, «Posición»): pegado a una esquina de la pantalla, a
 * una distancia de sus dos bordes. Panel y pastilla comparten el ancla: la pastilla sale en la esquina del panel más cercana
 * al borde y el panel, al abrirse, crece desde ahí. Todo en píxeles de la ventana y sin DOM (salvo `huecoVentana`), para
 * probarlo solo.
 */

/** Esquina: `b`/`t` (abajo/arriba) + `r`/`l` (derecha/izquierda). */
export type Esquina = 'br' | 'bl' | 'tr' | 'tl'

/** `x`: distancia al borde izquierdo o derecho. `y`: al borde de abajo de la ventana, o al de abajo de la barra azul si la
 *  esquina es de arriba. */
export type Ancla = { esq: Esquina; x: number; y: number }

/** Donde puede estar la caja: la ventana, menos la barra azul de arriba (`arriba` = su alto). */
export type Hueco = { ancho: number; alto: number; arriba: number }

/** Una caja ya pintada: esquina superior izquierda y tamaño. */
export type Caja = { izq: number; arriba: number; ancho: number; alto: number }

/** Posición `fixed`: solo los dos lados que tocan (`right` o `left`, `bottom` o `top`). */
export type EstiloAnclado = { left?: number; right?: number; top?: number; bottom?: number }

/** De fábrica: abajo a la derecha, a 16 px. */
export const ANCLA_DE_FABRICA: Ancla = { esq: 'br', x: 16, y: 16 }

/** Alto de la barra azul (`--spacing-navbar` de tokens.css): la caja nunca se mete debajo. */
export const ALTO_BARRA_PX = 64

const ESQUINAS: readonly Esquina[] = ['br', 'bl', 'tr', 'tl']

/** `v` entre `min` y `max`; si no cabe (`max < min`), `min`. */
const recortar = (v: number, min: number, max: number) => Math.min(Math.max(v, min), Math.max(min, max))

/** Al soltar: la esquina más cercana al CENTRO de la caja y la distancia de la caja a esos dos bordes. */
export function anclaAlSoltar(caja: Caja, hueco: Hueco): Ancla {
  const derecha = caja.izq + caja.ancho / 2 > hueco.ancho / 2
  const abajo = caja.arriba + caja.alto / 2 > (hueco.arriba + hueco.alto) / 2
  const esq: Esquina = abajo ? (derecha ? 'br' : 'bl') : derecha ? 'tr' : 'tl'
  const x = derecha ? hueco.ancho - (caja.izq + caja.ancho) : caja.izq
  const y = abajo ? hueco.alto - (caja.arriba + caja.alto) : caja.arriba - hueco.arriba
  return { esq, x: Math.max(0, Math.round(x)), y: Math.max(0, Math.round(y)) }
}

/** Posición de una caja de `ancho × alto` con ese ancla. Las distancias se recortan para que quepa entera entre la barra
 *  azul y los bordes de la ventana; el ancla guardada no cambia, así que si la ventana vuelve a crecer la caja vuelve a su
 *  sitio. */
export function estiloAnclado(ancla: Ancla, ancho: number, alto: number, hueco: Hueco): EstiloAnclado {
  const x = recortar(ancla.x, 0, hueco.ancho - ancho)
  const y = recortar(ancla.y, 0, hueco.alto - hueco.arriba - alto)
  return {
    ...(ancla.esq[1] === 'r' ? { right: x } : { left: x }),
    ...(ancla.esq[0] === 'b' ? { bottom: y } : { top: hueco.arriba + y }),
  }
}

/** Durante el arrastre: la esquina superior izquierda, sin salir de la ventana ni meterse bajo la barra azul. */
export function dentroDelHueco(izq: number, arriba: number, ancho: number, alto: number, hueco: Hueco): { izq: number; arriba: number } {
  return { izq: recortar(izq, 0, hueco.ancho - ancho), arriba: recortar(arriba, hueco.arriba, hueco.alto - alto) }
}

/** Lo leído del navegador, si es un ancla de verdad (esquina conocida y distancias finitas y no negativas); si no, null. */
export function anclaValida(v: unknown): Ancla | null {
  if (typeof v !== 'object' || v === null) return null
  const { esq, x, y } = v as Record<string, unknown>
  if (typeof esq !== 'string' || !ESQUINAS.includes(esq as Esquina)) return null
  if (typeof x !== 'number' || typeof y !== 'number') return null
  if (!Number.isFinite(x) || !Number.isFinite(y) || x < 0 || y < 0) return null
  return { esq: esq as Esquina, x, y }
}

/** El hueco de esta ventana. `clientWidth` y no `innerWidth`: sin la barra de scroll, que el `right` de un `fixed` no cuenta.
 *  jsdom da 0 en `clientWidth` y `clientHeight`; de ahí la vuelta a `innerWidth` e `innerHeight`. */
export function huecoVentana(): Hueco {
  return {
    ancho: document.documentElement.clientWidth || window.innerWidth,
    alto: document.documentElement.clientHeight || window.innerHeight,
    arriba: ALTO_BARRA_PX,
  }
}
```

```ts
/**
 * Panel flotante «Carga de técnicos» (spec 0.9.20): lo que recuerda el navegador (estado, alcance y sitio) y el aviso de un
 * solo uso con el que el panel pide a Asignaciones el filtro de un técnico. En shared porque lo usan la barra azul (app), el
 * marco y Asignaciones (módulo taller).
 */

export type EstadoPanelCarga = 'abierto' | 'minimizado' | 'cerrado'
export type AlcancePanelCarga = 'pedidos' | 'total'
export type PanelCarga = { estado: EstadoPanelCarga; alcance: AlcancePanelCarga; ancla: Ancla }

/** Clave de localStorage. Es del navegador, no del usuario (en el taller se comparten PCs), y cerrar sesión no la borra. */
export const CLAVE_PANEL_CARGA = 'panelCarga'

/** De fábrica: abierto, en Pedidos, abajo a la derecha a 16 px. */
export const PANEL_DE_FABRICA: PanelCarga = { estado: 'abierto', alcance: 'pedidos', ancla: ANCLA_DE_FABRICA }

/** Lo guardado, campo a campo: lo que no se pueda leer o no tenga forma válida se queda en lo de fábrica. */
export function leerPanelCarga(): PanelCarga {
  let guardado: unknown = null
  try {
    guardado = JSON.parse(localStorage.getItem(CLAVE_PANEL_CARGA) ?? 'null')
  } catch {
    guardado = null
  }
  const o = typeof guardado === 'object' && guardado !== null ? (guardado as Record<string, unknown>) : {}
  const estado = o.estado
  const alcance = o.alcance
  return {
    estado: estado === 'abierto' || estado === 'minimizado' || estado === 'cerrado' ? estado : PANEL_DE_FABRICA.estado,
    alcance: alcance === 'pedidos' || alcance === 'total' ? alcance : PANEL_DE_FABRICA.alcance,
    ancla: anclaValida(o.ancla) ?? PANEL_DE_FABRICA.ancla,
  }
}

/** Si no se puede guardar (modo privado, almacenamiento bloqueado), la elección dura lo que la página. */
function guardar(panel: PanelCarga) {
  try {
    localStorage.setItem(CLAVE_PANEL_CARGA, JSON.stringify(panel))
  } catch {
    // sin almacenamiento: dura lo que la página
  }
}

/** Se relee al reiniciar los stores (cierre de sesión): lo recordado sigue siendo lo del navegador. */
export const panelCarga = crearStoreLeido(leerPanelCarga)

function cambiar(cambio: Partial<PanelCarga>) {
  const nuevo = { ...panelCarga.get(), ...cambio }
  panelCarga.set(nuevo)
  guardar(nuevo)
}

export const abrirPanelCarga = () => cambiar({ estado: 'abierto' })
export const minimizarPanelCarga = () => cambiar({ estado: 'minimizado' })
export const cerrarPanelCarga = () => cambiar({ estado: 'cerrado' })
export const cambiarAlcancePanelCarga = (alcance: AlcancePanelCarga) => cambiar({ alcance })
/** Se llama al SOLTAR un arrastre, no en cada movimiento. */
export const moverPanelCarga = (ancla: Ancla) => cambiar({ ancla })
/** Botón «Carga» de la barra azul: abierto → cerrado; minimizado o cerrado → abierto. */
export const alternarPanelCarga = () => cambiar({ estado: panelCarga.get().estado === 'abierto' ? 'cerrado' : 'abierto' })

export function usePanelCarga(): PanelCarga {
  return useStore(panelCarga)[0]
}

/** Aviso de un solo uso: el técnico que se ha pulsado en el panel, a la espera de que Asignaciones ponga su filtro. */
const filtroTecnicoPedido = crearStore<number | null>(null)

/** Pulsar un técnico en el panel. */
export function pedirFiltroPorTecnico(idTec: number): void {
  filtroTecnicoPedido.set(idTec)
}

/** Para Asignaciones: entrega a `aplicar` el técnico pedido, ahora (si se pidió desde otra pantalla antes de montarse la
 *  vista) y cada vez que se pida después, y lo vacía al entregarlo. Devuelve la baja. */
export function recibirFiltroPorTecnico(aplicar: (idTec: number) => void): () => void {
  function entregar() {
    const idTec = filtroTecnicoPedido.get()
    if (idTec === null) return
    filtroTecnicoPedido.set(null)
    aplicar(idTec)
  }
  entregar()
  const baja = filtroTecnicoPedido.subscribe(entregar)
  return () => {
    baja()
  }
}
```

```ts
import { useRef, type MouseEvent as EventoRaton, type PointerEvent as EventoPuntero, type RefObject } from 'react'
import { anclaAlSoltar, dentroDelHueco, huecoVentana, type Ancla } from '@/shared/lib/anclaPanel'

/** Por debajo de este movimiento (px) no es un arrastre: es un clic. */
export const UMBRAL_ARRASTRE_PX = 4

type EnCurso = { id: number; x0: number; y0: number; dx: number; dy: number; ancho: number; alto: number; izq: number; arriba: number; movido: boolean }

/**
 * Arrastre con pointer events (spec 0.9.20 §2, «Posición»). Los manejadores van en el asa (la cabecera del panel o la
 * pastilla entera) y mueven `cajaRef`, que es `fixed`.
 * - Mientras se mueve, la caja se pinta con `left/top`, sin salir de la ventana ni meterse bajo la barra azul, y lleva
 *   `data-arrastrando` (useColocarAnclado no la toca entonces).
 * - Al soltar, `onSoltar` recibe el ancla (esquina más cercana + distancias); colocarla según el ancla es cosa de
 *   useColocarAnclado.
 * - Un elemento con `data-no-arrastre` (los botones de la cabecera, la × de la pastilla) no empieza arrastre.
 * - Si hubo arrastre, el clic que el navegador manda al soltar se anula (`onClickCapture`): soltar la pastilla no la abre.
 */
export function useArrastre(cajaRef: RefObject<HTMLElement | null>, onSoltar: (ancla: Ancla) => void) {
  const enCurso = useRef<EnCurso | null>(null)
  const anularClic = useRef(false)

  function onPointerDown(e: EventoPuntero<HTMLElement>) {
    if (e.button !== 0) return
    if (e.target instanceof Element && e.target.closest('[data-no-arrastre]')) return
    const caja = cajaRef.current
    if (!caja) return
    const r = caja.getBoundingClientRect()
    enCurso.current = {
      id: e.pointerId, x0: e.clientX, y0: e.clientY, dx: e.clientX - r.left, dy: e.clientY - r.top,
      ancho: r.width, alto: r.height, izq: r.left, arriba: r.top, movido: false,
    }
    anularClic.current = false
    e.currentTarget.setPointerCapture(e.pointerId)
  }

  function onPointerMove(e: EventoPuntero<HTMLElement>) {
    const a = enCurso.current
    const caja = cajaRef.current
    if (!a || !caja || e.pointerId !== a.id) return
    if (!a.movido && Math.hypot(e.clientX - a.x0, e.clientY - a.y0) < UMBRAL_ARRASTRE_PX) return
    a.movido = true
    caja.dataset.arrastrando = ''
    const p = dentroDelHueco(e.clientX - a.dx, e.clientY - a.dy, a.ancho, a.alto, huecoVentana())
    a.izq = p.izq
    a.arriba = p.arriba
    caja.style.left = `${p.izq}px`
    caja.style.top = `${p.arriba}px`
    caja.style.right = ''
    caja.style.bottom = ''
  }

  function terminar(e: EventoPuntero<HTMLElement>) {
    const a = enCurso.current
    if (!a || e.pointerId !== a.id) return
    enCurso.current = null
    if (e.currentTarget.hasPointerCapture(e.pointerId)) e.currentTarget.releasePointerCapture(e.pointerId)
    if (!a.movido) return
    if (cajaRef.current) delete cajaRef.current.dataset.arrastrando
    anularClic.current = true
    onSoltar(anclaAlSoltar({ izq: a.izq, arriba: a.arriba, ancho: a.ancho, alto: a.alto }, huecoVentana()))
  }

  function onClickCapture(e: EventoRaton<HTMLElement>) {
    if (!anularClic.current) return
    anularClic.current = false
    e.preventDefault()
    e.stopPropagation()
  }

  return { onPointerDown, onPointerMove, onPointerUp: terminar, onPointerCancel: terminar, onClickCapture }
}
```

```ts
import { useLayoutEffect, type RefObject } from 'react'
import { estiloAnclado, huecoVentana, type Ancla } from '@/shared/lib/anclaPanel'

const px = (v: number | undefined) => (v === undefined ? '' : `${v}px`)

/** Pinta la caja `fixed` según el ancla, recortada a la ventana (spec 0.9.20 §2). Se repite en cada render (el alto cambia
 *  con los datos) y al cambiar el tamaño de la ventana. Durante un arrastre (`data-arrastrando`) no la toca: manda el
 *  puntero. */
export function useColocarAnclado(cajaRef: RefObject<HTMLElement | null>, ancla: Ancla) {
  useLayoutEffect(() => {
    function colocar() {
      const caja = cajaRef.current
      if (!caja || caja.dataset.arrastrando !== undefined) return
      const e = estiloAnclado(ancla, caja.offsetWidth, caja.offsetHeight, huecoVentana())
      caja.style.left = px(e.left)
      caja.style.right = px(e.right)
      caja.style.top = px(e.top)
      caja.style.bottom = px(e.bottom)
    }
    colocar()
    window.addEventListener('resize', colocar)
    return () => window.removeEventListener('resize', colocar)
  })
}
```

```tsx
 *  no monta nada ni pide nada. Abierto, minimizado (pastilla) o cerrado, según lo que recuerde el navegador. */

function PanelCargaVisible() {
  const recordado = usePanelCarga()
  // Abierto o minimizado pide (la pastilla enseña datos); cerrado, nada.
  const consulta = useCargaTecnicos(recordado.estado !== 'cerrado')
  // Ratón encima (o arrastrando): se pinta la última copia, para que ninguna fila se mueva bajo el cursor. Se apunta en QUÉ
  // estado entró el ratón: al minimizar o cerrar con el ratón encima, el `pointerleave` no llega (la caja desaparece), y así
  // la pastilla o el panel nuevos no se quedan congelados.
  const [encimaDe, setEncimaDe] = useState<EstadoPanelCarga | null>(null)
  if (recordado.estado === 'cerrado' && encimaDe !== null) setEncimaDe(null)
  const datos = useCongelado(consulta.data, encimaDe === recordado.estado)
  const raton = { onPointerEnter: () => setEncimaDe(recordado.estado), onPointerLeave: () => setEncimaDe(null) }

  if (recordado.estado === 'cerrado') return null
  if (recordado.estado === 'minimizado') return <Pastilla recordado={recordado} datos={datos} {...raton} />

/** `valor`, salvo mientras `congelado`: entonces, el último que se pintó. Ajuste de estado durante el render, sin efecto. */
function useCongelado<T>(valor: T, congelado: boolean): T {
  const [copia, setCopia] = useState(valor)
  if (!congelado && copia !== valor) setCopia(valor)
  return congelado ? copia : valor
}
```

```ts
  const total = async () => Number(((await fila.getByText(/^\d+%$/).first().textContent()) ?? '').replace('%', ''))
```
